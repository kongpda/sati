Office wiring: `sati init --desktop` prints the Claude Desktop entry for a project, and `--project` takes the project folder as well as a slug, so a desktop app can start the server from anywhere. Agents without a shell can write a handoff (`handoff_write`) and tick or add checklist steps (`task_update` with `tick` and `addSteps`). The general rules and workflow say how to keep cards for Word, Excel, PowerPoint and PDF files. Four new starter templates: `content-calendar`, `monthly-report`, `proposal`, `meeting-notes`.
