Projects have a kind. `sati init --kind general` (or `sati settings --kind general`, or Settings in the web UI) sets up a project for plans, todos and notes, such as an event or a campaign: the UI hides Features and the Agents page, the guard is off, agents get a shorter rules block, and the MCP server leaves out the feature and lock tools. Code projects are unchanged.
