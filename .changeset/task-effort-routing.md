Tasks take an optional `effort` (`light`, `standard`, `deep`). The brief and task lists show it, `task list --effort light` finds tasks an agent can hand to a subagent on a small, cheaper model, and the agent rules say how. Also: a holder's claim renewal keeps its task locks alive, a lock cannot be tagged with another agent's task, doctor's upgrade hint adds `--yes`, and agents skip `sati_brief` when the session already opened with it.
