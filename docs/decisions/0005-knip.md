# 0005. Add knip to find unused code and dependencies

- Status: accepted (2026-11-10, owner decision in docs/review-followups.md)
- Date: 2026-11-10

## Context

The 2026-11-10 review found that no dead-code search had ever run (review WP10). Biome and
`tsc` do not report unused exports, files or dependencies across packages. Unused exports make
a package's surface look larger than it is, and unused dependencies cost install size, which
PLAN keeps under 15 MB.

## Decision

Add `knip` 6.43.0 as a root dev dependency, pinned like the other tools, with a `knip.json`
and a `pnpm knip` script. Its plugins find the entry points: each package's `exports` and
`bin`, the Vite, Vitest, Playwright and tsdown configs, and the test files. The config adds
the scripts under `scripts/` and `bench/`, and ignores three cli dev dependencies that are
used on purpose without an import knip can see:

- `ulid` and `drizzle-orm` are bundled into the published CLI.
- `@sati/ui` is built first so `scripts/copy-ui.mjs` can copy its `dist/`.

`pnpm knip` is not part of `pnpm lint`. Run it before a release and after large removals.

## Consequences

- The first run found 8 exports used only inside their own file. They are no longer exported,
  so `pnpm knip` reports nothing.
- One more dev tool to keep up to date. It is not shipped to users.
- Node 26 prints a `module.register()` deprecation warning when knip loads configs. It is
  harmless.

## Alternatives considered

- `ts-prune`: in maintenance mode, and its README points to knip. It finds only unused
  exports, not unused files or dependencies.
- A Biome rule: Biome checks one file at a time and cannot see cross-package use.
- No tool: the review showed that nobody runs the search by hand.
